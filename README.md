\# Mini-frontend pentru API-ul meu



\## Descriere

Aplicație simplă care afișează și creează postări folosind un API REST.



\## URL-ul API-ului

https://jsonplaceholder.typicode.com/posts



\## Funcționalități

\- GET: încarcă lista de postări.

\- POST: trimite o postare nouă în format JSON.

\- Căutare: filtrează postările după titlu.

\- Formularul validează câmpurile obligatorii.



\## Erori și status codes

\- 200: cererea GET a reușit.

\- 201: postarea a fost creată cu succes.

\- 4xx: sunt afișate mesaje de eroare pentru cereri respinse.

\- Eroare de rețea: este afișat un mesaj generic.



\## CORS

Frontend-ul folosește JSONPlaceholder, un API extern. Cererile din browser depind de permisiunile CORS ale API-ului.



\## Tehnologii

HTML, CSS și JavaScript.
